## 概要

本プロジェクトは、DJI Tello（および Tello EDU）ドローンをWebブラウザから操作・実験するためのオープンソース・コントローラーです。FastAPI、生UDPソケット通信、WebSocket、およびOpenCV（LineSegmentDetector / HSV色空間処理）を組み合わせて実装されています。

PCとTello間のUDP通信、有線LANとWiFiが共存する環境下でのパケットルーティング問題（マルチホーミング環境でのWiFiインターフェース直接バインド）、PCおよびスマートフォンからのレスポンシブな操作に対応しています。

---

## 設計思想と特徴

1. **生UDPソケットによるWiFiインターフェース明示的バインド**:
   PCが有線LAN（インターネット接続）と無線LAN（Tello AP接続: `192.168.10.x`）の双方に接続されている環境でも、OSのルーティングテーブルに依存せず、Tello側のIPアドレスへ確実にUDPパケット（コマンド送信 `8889`、テレメトリ受信 `8890`、映像受信 `11111`）を通信させます。
2. **実用的なLineTraceアルゴリズム (OpenCV LSD + 前処理)**:
   ガウシアンフィルター平滑化、HSV色相抽出、モルフォロジー演算、および `cv2.createLineSegmentDetector` (LSD) を用いて床面のライン線分を検出します。通常機体（前方微下向きカメラ）と改造機体（ほぼ真下向きカメラ）の双方の制御特性に対応しています。
3. **2010年代後半調のダークテーマ & レスポンシブUI**:
   過度なグラデーションや発光エフェクトを排し、可読性と実用性を重視したフラットなダークグレーテーマ（Visual Studio Code / GitHub Dark調）を採用しています。PCでのキーボード操作に加え、スマートフォン向けにオンスクリーン・バーチャルD-Padを提供しています。
4. **飛行ログ (Timeline CSV) と高画質静止画キャプチャ**:
   接続セッション毎にタイムスタンプ付きの飛行データ（バッテリー、高度、温度、姿勢角、速度、送信RC値、ライントレース検出状態）を1秒間隔でCSV保存します。また、最新の映像フレームを無劣化PNG形式で保存できます。

## 使い方と操作方法

### 1. Telloとの接続

1. ドローンの電源を入れ、LEDが点滅するまで数秒待ちます。
2. PCのWi-Fi接続先をTelloのアクセスポイント（例: `TELLO-XXXXXX`）に接続します。
3. ブラウザでコントローラー画面を開きます。
4. 有線LANを併用している場合は、「ネットワーク設定」パネルで「★Tello」と表示されているインターフェース（通常 `192.168.10.x`）を選択します。
5. 右上の「接続」ボタンをクリックします。ステータスが「接続中」になれば準備完了です。

---

### 2. 飛行制御（ボタン・キーボード）

| 操作 | ボタン | キーボード | 動作 |
|---|---|---|---|
| 離陸 | 「離陸」ボタン | `T` | 約1mの高さまで上昇して自動ホバリング |
| 着陸 | 「着陸」ボタン | `L` | その場で緩やかに下降し、着陸後モーター停止 |
| 緊急停止 | 「緊急停止」ボタン | `Space` | 即座に全モーターをカット（落下しますので緊急時のみ使用） |
| 前進 / 後退 | 画面内ボタン | `W` / `S` | 前後進（キー押下中のみ移動、離すと停止） |
| 左移動 / 右移動 | 画面内ボタン | `A` / `D` | 左右平行移動（Roll） |
| 上昇 / 下降 | 画面内ボタン | `R` / `F` | 垂直方向の昇降（Throttle） |
| 左旋回 / 右旋回 | 画面内ボタン | `Q` / `E` | 機首の回転（Yaw） |

> **注意**: 入力フォーム（テキスト入力欄）にフォーカスがある間は、誤操作防止のためキーボードショートカットが無効化されます。

---

### 3. スマートフォン・タブレットでの操作

スマートフォン等のタッチスクリーン端末からPCホストのIP（例: `http://192.168.10.2:8000`）にアクセスして操作する場合:

- **タッチ操縦パッド（D-Pad）**:
  - 左側パッド: 上昇(`R`)、下降(`F`)、左旋回(`Q`)、右旋回(`E`)
  - 右側パッド: 前進(`W`)、後退(`S`)、左移動(`A`)、右移動(`D`)
  - 中央: 離陸(`T`)、着陸(`L`)、非常停止(`Space`)
- **操作方式**:
  - ボタンを押している（長押ししている）間のみRC信号を送信し、指を画面から離すと即座に信号が解放（ニュートラル・ホバリング）されます。
- **モバイルタブ切り替え**:
  - 画面幅が狭い端末では、画面下部にタブ（[LineTrace] [飛行設定] [QR] [通信]）が表示され、目的のパネルをワンタップで切り替えて表示できます。

---

### 4. LineTrace（LSD線分検出自動追従）

1. ドローンと接続後、「映像開始」ボタンを押してカメラストリーミングを開始します。
2. カメラ画角内に追従対象のライン（床面のビニールテープ等）が映る状態にします。
3. **機体カメラタイプ**を選択します:
   - **通常機体 (前方微下向きカメラ)**: 標準のTello機体。ラインの傾きに合わせてYaw旋回を行い、前進します。
   - **改造機体 (ほぼ真下カメラ)**: カメラ角度を下向きに変更した実験機体。横ズレを左右平行移動（Roll）で直接補正しながら前進します。
4. **色プリセット**（赤/青/黄/黒）を選択するか、HSVスライダーで対象色を調整します。
5. 「LineTrace表示」スイッチをONにすると、検出された線分（黄色/緑線）や進行方向ベクトル（シアン矢印）が重畳表示されます。
6. 「追従制御」スイッチをONにすると、自動追従モードが開始されます。

#### 安全機能（フェイルセーフ）
- **ライン見失い時**: ラインが画角から外れた場合、前進および旋回・横移動を直ちにゼロクリアし、その場で安定ホバリング状態を維持します。
- **直角コーナー検出時**: 主ラインの先端に直交する線分を検知した場合、コースアウトを防ぐため自動的に前進速度を微速（約5以下）に落とし、旋回を優先します。

---

### 5. 静止画撮影（PNGダウンロード）

- 映像表示バーの「撮影」ボタンをクリックすると、現在のフレームを高画質PNG画像としてダウンロードします。
- 保存ファイル名: `TELLO_YYYY-MM-DD-HH-mm-ss.png`
- バックエンドのキャプチャAPI（`/api/screenshot`）を優先利用し、通信状況に応じたフォールバックも備えています。

---

### 6. 飛行ログ（Timeline CSV記録）

- 接続セッション開始から切断まで、1秒間隔で飛行ログが自動記録されます。
- 「飛行操作」パネルの「飛行ログCSV」ボタンをクリックすると、最新セッションのCSVファイル（`logs/TELLO_YYYY-MM-DD-HH-mm-ss.csv`）をブラウザから直接ダウンロードできます。
- **記録項目**: タイムスタンプ、飛行時間、バッテリー残量、高度、温度、姿勢角(pitch, roll, yaw)、速度(vx, vy, vz)、送信RC値(lr, fb, ud, yaw)、制御モード(manual/linetrace/idle)、LineTrace検出状態。

---

### 7. QRコード認識・連携

- カメラ映像内のQRコードを検出し、テキストおよびURLを保存・表示します。
- 学籍番号・ユーザー名を設定してCSVファイルとしてまとめてエクスポートできます。

## スマートフォン利用時の注意事項（HTTP環境のセキュリティポリシー）

本アプリケーションをPCで稼働させ、同一Wi-Fiネットワーク上のスマートフォンやタブレットのブラウザからアクセスする場合、接続は `http://<PCのIPアドレス>:8000` となり、ブラウザ仕様上 **Non-Secure Context（非暗号化HTTP通信）** として扱われます。

モダンブラウザ（iOS Safari、Android Chrome等）のセキュリティポリシーにより、以下の機能制限が生じる場合があります:

1. **クリップボード直接書き込み (`navigator.clipboard.writeText`)**:
   - HTTP環境ではブロックされます。本アプリでは古いブラウザ仕様に準拠したフォールバック（`document.execCommand('copy')`）および手動コピー用ダイアログを用意しており、エラーで処理が中断しないよう配慮しています。
2. **端末センサー (`DeviceOrientation` / ジャイロ)**:
   - 端末を傾けてのチルト操縦はHTTP環境では権限が拒否されます。そのため、本アプリでは**画面上のオンスクリーンD-Pad（長押し操作）**による安全なタッチイベント操縦を標準としています。
3. **ブラウザ通知 API / WebRTC**:
   - Non-Secure Contextでは一部無効化されますが、本アプリは標準のMJPEGストリームとWebSocket (`ws://`) を使用しているため、操縦・テレメトリ・映像受信はいずれも正常に機能します。
4. **安全上の推奨**:
   - スマートフォンからの操縦中であっても、万一の通信遅延や端末スリープに備え、PC側の画面でも緊急停止キー（`Space`）を操作できる状態にしておくことを推奨します。

## トラブルシューティング

1. **「接続」を押しても接続中にならない**:
   - PCのWi-FiがTelloのSSID（`TELLO-XXXXXX`）に正しく接続されているか確認してください。
   - 有線LANを併用している場合、「ネットワーク設定」でTello側のIPアドレス（`192.168.10.x`）を選択して再試行してください。
   - Windows Defender等のファイアウォールがUDP 8889, 8890, 11111を遮断していないか確認してください。
2. **映像ストリーミングが表示されない**:
   - バッテリー残量が少なくなると（約10%以下）、Tello側が省電力のため映像送信を停止する場合があります。バッテリーを交換・充電してください。
3. **ライントレースが線を見失う**:
   - 床面の色とラインの色のコントラストが十分か確認し、スライダーでHSVパラメータを微調整してください。
   - 周囲の照明が暗すぎる、または強烈な逆光や床面の強い反射（テカリ）がある場合、LSD線分検出の精度が低下することがあります。

## 安全上のご注意と免責事項

- 本ソフトウェアによる自動追従および遠隔操縦は実験的・学習目的の実装です。
- 飛行環境（風、照明、床面の反射、障害物、Wi-Fi電波の混雑など）によって予期せぬ挙動が発生する可能性があります。
- 屋内の十分な広さのある安全な空間（人や壊れやすい物が周囲にない場所）で、プロペラガードを必ず装着した上で飛行させてください。
- 操縦者は常にドローンを目視し、異常を感じた場合は直ちに「緊急停止（Space）」または手動着陸を行ってください。
